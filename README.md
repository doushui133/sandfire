# 烈沙行动

在原创沙漠地图「烈沙镇」上打一场 5v5 爆破战。你选择一方，和四名机器人队友迎战五名对手。进攻方可以在 A 点或 B 点安放炸弹并守到爆炸。防守方需要阻止安放，或在爆炸前拆弹。先赢 8 局的一方获胜。

**在线游玩：<https://doushui133.github.io/sandfire/>**（电脑用键盘鼠标，手机横屏用触屏操作）

## 运行与部署

使用支持 WebGL2 的新版 Chrome、Edge 或 Safari。手机请横屏游玩。iPhone 可在 Safari 中选择「分享 → 添加到主屏幕」，再从主屏幕打开游戏以全屏游玩。

本地试玩时，在项目根目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。部署时，将本目录的内容放在 `sandfire` 仓库根目录，在仓库的 Settings → Pages 中选择从分支发布，并选中该分支的根目录。项目使用相对路径，无需构建。

## 键鼠操作

| 输入 | 动作 |
| --- | --- |
| W / A / S / D | 前进、左移、后退、右移 |
| 鼠标移动、左键 | 瞄准、开火。阵亡后左键切换观察对象 |
| 右键 | 狙击步枪切换瞄准倍率，匕首重击 |
| 空格、Ctrl 或 C、Shift | 跳跃、按住蹲下、按住静步 |
| R、G | 换弹、丢弃当前武器或炸弹 |
| 1 / 2 / 3 / 4 | 选择主武器、手枪、匕首、炸弹 |
| 滚轮、Q | 循环选择已持有的武器、切回上一把 |
| E | 在包点按住安放炸弹，在已安放的炸弹旁按住拆除 |
| B | 在回合开始时于出生点打开或关闭购买菜单，可点选商品或按对应数字购买 |
| Tab、Esc | 按住查看记分板、暂停游戏 |

## 触屏操作

「操作」默认选「自动」，按设备的主指针选择触屏或键鼠。桌面测试时，选「触屏」并保持窗口横向，鼠标也可以在游戏画面上按住并拖动。菜单里的「触屏灵敏度」独立于鼠标设置。

- 左侧空白处按下即出现摇杆。轻推可以静步，推到外圈可以全速移动，松手停下。
- 在右侧空白处滑动瞄准。按住「开火」时也能拖动瞄准。自动武器可以连射，半自动武器每发需点一次。
- 点「跳」跳跃，点「蹲」切换蹲姿，点「换弹」补充弹匣。狙击步枪可点「开镜」切换倍率，匕首可按住「重击」。
- 点「切枪」循环选择，或直接点底部武器栏。「丢弃」放下当前可丢弃的武器或炸弹。
- 在包点或炸弹旁，按住高亮的「使用」直到进度条走完。在出生点出现「购买」时可打开商店，点商品购买，点「关闭」返回。
- 点「比分」查看记分板，点「关闭比分」返回。「暂停」可调整灵敏度、继续游戏或退出到菜单。阵亡后轻点右侧切换观察对象。

## 画质

「自动」为触屏主指针或软件渲染设备选择「流畅」，其他设备选择「高」。手动选择画质后页面会重新加载。「流畅」降低阴影和材质开销，手机的渲染像素比最高为 1.25。两种预设都会按帧耗时动态调整分辨率。

## 项目结构

`index.html` 包含加载器、菜单及 HUD；`touch.css` 提供横屏布局和触屏控件。脚本按依赖顺序载入，共用 `window.G`。

| 脚本 | 用途 |
| --- | --- |
| `vendor/three.min.js` | 本地 three.js r128 渲染引擎 |
| `js/look.js` | 过滤鼠标移动中的突发跳变 |
| `js/core.js` | 共享状态、数学工具、设置、键鼠输入和鼠标锁定 |
| `js/audio.js` | 用 Web Audio 合成枪声、脚步、环境反馈与空间音效 |
| `js/touch.js` | 操作模式、灵敏度、摇杆与多指输入，调试状态见 `G.Touch` |
| `js/textures.js` | 加载时生成程序化纹理与世界纹理数组 |
| `js/map.js` | 烈沙镇布局、碰撞查询、射线检测、导航和雷达底图 |
| `js/mapgeo.js` | 构造用于小镇渲染和光照烘焙的静态几何数据 |
| `js/gfx.js` | 画质预设、着色器、天空、阴影和烘焙光照 |
| `js/geom.js` | 角色与武器建模共用的几何工具 |
| `js/gunmodels.js` | 生成各武器的三维模型 |
| `js/mapmesh.js` | 将小镇、道具和贴花组装成可渲染网格 |
| `js/fx.js` | 烟尘、命中和其他战斗特效 |
| `js/weapons.js` | 武器数据、射击、后坐力、换弹和掉落物 |
| `js/viewmodel.js` | 第一人称手臂、武器与动作 |
| `js/player.js` | 移动物理、玩家控制、死亡镜头与观战 |
| `js/ragdoll.js` | 角色倒地时的布娃娃物理 |
| `js/soldier.js` | 第三人称士兵模型和动画 |
| `js/bots.js` | 机器人感知、路线、战术与交战 |
| `js/game.js` | 回合、经济、购买、伤害、胜负与炸弹逻辑 |
| `js/hud.js` | 雷达、状态、战斗提示、商店和记分板 |
| `js/main.js` | 启动、渲染循环、动态分辨率、菜单和暂停 |

渲染使用本地的 three.js r128。小镇的烘焙光照位于 `assets/lightmap.png`，与地图几何数据对应。墙面、地面等表面纹理在加载时由程序生成。
