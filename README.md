# 烈沙行动

在原创沙漠地图「烈沙镇」上打一场 5v5 爆破战。你选择一方，和四名机器人队友迎战五名对手。进攻方可以在 A 点或 B 点安放炸弹并守到爆炸。防守方需要阻止安放，或在爆炸前拆弹。先赢 8 局的一方获胜。

**在线游玩：<https://doushui133.github.io/sandfire/>**（电脑用键盘鼠标，手机横屏用触屏操作）

## 运行与部署

使用支持 WebGL2 的新版 Chrome、Edge 或 Safari。手机请横屏游玩。iPhone 可在 Safari 中选择「分享 → 添加到主屏幕」，再从主屏幕打开游戏以全屏游玩。

本地试玩时，在项目根目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。部署时，将本目录的内容放在 `sandfire` 仓库根目录，在仓库的 Settings → Pages 中选择从分支发布，并选中该分支的根目录。项目使用相对路径，无需构建。

首次进入会先显示主菜单（程序生成的角色与枪械），高清 Rocketbox 角色、CC0 枪械与 Poly Haven 扫描贴图在后台按优先级下载；手机「均衡/流畅」使用 `assets/chars/m/` 与 `assets/guns/m/` 的半尺寸贴图（运行 `tools/make-mobile-assets.ps1` 生成）。菜单右下角或 `#status` 会显示进度。再次打开时 `sw.js` 会缓存静态资源加速载入——每次发布请同时把 `sw.js` 里的 `CACHE_VERSION` 与 `js/main.js` 引用的版本保持一致，避免玩家卡在旧脚本上。

## 键鼠操作

| 输入 | 动作 |
| --- | --- |
| W / A / S / D | 前进、左移、后退、右移 |
| 鼠标移动、左键 | 瞄准、开火。阵亡后左键切换观察对象 |
| 右键 | 狙击步枪切换两档倍率，匕首重击 |
| 空格、C、Shift | 跳跃、按住蹲下、按住静步。全屏并成功锁定键盘后也可用 Ctrl 蹲下 |
| R、G | 换弹、丢弃当前物品 |
| 1 / 2 / 3 / 4 / 5 | 主武器、手枪、匕首、投掷物、炸弹。点 4 切换投掷物，按住 4 弹出投掷物轮盘 |
| 6 / 7 / 8 / 9 | 直接拿高爆手雷、闪光弹、烟雾弹、燃烧瓶/燃烧弹 |
| 滚轮、Q | 循环选择已持有的物品、切回上一栏 |
| E | 在包点按住安放炸弹，在已安放的炸弹旁按住拆除；对着地上的枪按 E 交换（两把枪各自保留子弹） |
| B | 出生点购买。依次按分类和商品的数字，也可点击。B 或 Esc 关闭 |
| Tab、Esc | 按住查看记分板、暂停游戏 |
| M | 打开或关闭大地图 |

鼠标灵敏度之外还有单独的开镜灵敏度。准星默认小而细，带中心点，移动和开火时平滑地扩大并有上限；可以调大小、间隙和颜色，或改成固定准星。原始输入默认开启。视角过滤只丢掉物理上不可能的跳变，正常移动和甩枪不会被拖延或平滑。

移动有加速度：起步约 0.33 秒到全速，松手约 0.3 秒滑停；按住反方向键可在约 0.1 秒内急停，急停后第一枪就是站立精度（速度低于最高速度约三成时不再有移动误差）。每把自动武器有固定的弹道：步枪前八到十发明显上跳，之后左右摆动，需要往下、往反方向压枪；停火约半秒后弹道复位。

默认开启「全屏游玩（推荐）」。失去鼠标锁定时点击暂停画面继续，刚按 Esc 后稍等一秒再点。虚拟机或远程桌面可能无法锁定鼠标。在嵌入预览中可用普通鼠标操作，完整锁定请直接打开游戏页面。

## 触屏操作

- 横屏后，左侧空白处按下出现摇杆。摇杆中心会跟着拇指走，拇指滑远后往回收也能马上换方向。轻推静步，推过约三成就到静步速度，约六成进入跑步；松开摇杆自动急停（可在设置里关掉「摇杆回中急停」）。平板上摇杆和按钮按屏幕尺寸放大。
- 右侧空白处滑动瞄准：按手指速度计算，慢拖接近 1:1 更精细，快甩最多约 2 倍，60 Hz 和 120 Hz 屏幕转得一样多。按住开火键时也可以瞄准。开镜使用单独的灵敏度，垂直和水平可以分开调。
- 右下角是大开火键，跳、蹲、换弹、开镜和「武器」排在拇指够得到的弧线上。投掷和使用在左下，左侧开火键在摇杆上方，可以在设置里关闭。武器栏在底部中间。地图、购买、比分、暂停是右上角的小按钮。
- 主菜单和暂停里可以「自定义键位」：拖动每个按钮，用滑杆或双指捏合改大小，并调节整体透明度。点「恢复默认」回到出厂布局，点「保存」写入并离开编辑。
- 点底部武器栏直接切枪；点「武器」循环切换，长按丢弃当前武器。点「投掷」装备或切换投掷物，长按「投掷」或从它往上滑会弹出已有投掷物，滑到想要的那颗松手即选中。按住开火蓄力（约 0.65 秒蓄满），松手投出；按住「近抛」松手可短抛。
- 靠近地上的枪时「使用」会亮起并显示枪名，点一下交换。在包点或炸弹旁按住高亮的「使用」直到进度条完成。点「跳」「蹲」「换弹」控制动作。狙击步枪可点「开镜」，匕首可按住「重击」。
- 辅助瞄准只在准星靠近看得见的目标时轻轻变慢，并有一点吸附；隔墙和烟雾不会吸过去。可开启自动开火。陀螺仪瞄准有自己的灵敏度。
- 阵亡后轻点右侧切换观察对象。

## 界面

界面用深色半透明面板、1 像素描边和系统字体。生命、护甲、金钱和弹药靠在边角：血量和护甲是条加数字，弹药是大号数字配当前武器的侧视白剪影。武器栏带剪影和按键。顶部是回合计时、双方比分、存活点和炸弹状态。左上角雷达在桌面约 240 像素，手机上约为屏幕高度的 28%（至少 110 像素）：墙是深色，可行走的地面是浅色，并标出 A/B、出生点、队友朝向、最近约 3 秒内见过的敌人，以及携带、掉落或已安放的炸弹。击杀信息读作「击杀者 · 武器剪影 · 被击杀者」，爆头和穿墙单独标出，你的击杀会高亮。购买菜单按分类列出卡片（剪影、价格，以及伤害、射速、精度、机动）。记分板按阵营分色，并标出你所在的一行。

每次击杀会在屏幕下方中间弹出骷髅徽章（不用文字框）：普通击杀是银色骷髅，爆头是带弹孔的金色骷髅和红色准星环，刀杀、手雷、穿墙各有标记，连杀时徽章下排出对应数量的小骷髅，五杀带王冠。阵亡时镜头先受击震动、短暂慢放，再拉出到第三人称看自己的身体倒下，随后切到击杀者（橙色轮廓高亮），卡片显示对方名字、武器和剩余血量；轻点或点击可跳过。主菜单背景是小镇的低分辨率航拍（低画质和软件渲染用静帧）。

每回合结束时，胜负横幅里会显示「回合最佳」：胜方击杀最多（相同时看伤害）的人，安放或拆除炸弹、残局翻盘会单独标出；你拿到时是金色。阵亡卡片会多一行伤害统计：你对击杀者造成的伤害和命中次数，以及对方对你造成的伤害。

「声音指示」会在准星周围用短暂的箭头标出附近敌人的枪声（橙色）、脚步和换弹（白色）、投掷物弹跳和爆炸（黄色）的方向，越近越亮，最多同时六个。触屏默认开启，键鼠默认关闭，可在设置里切换。

## 模式

主菜单可以选「竞技爆破」（默认，5v5 安放/拆除炸弹，先赢 8 局）或「练枪死斗」：5v5 团队死斗，没有炸弹和购买，阵亡 2 秒后在远离敌人、敌人看不到的地方复活，复活后 1.5 秒无敌（开枪会提前结束）。先到 50 杀或 8 分钟结束时击杀多的一方获胜。下次复活用的武器可选步枪、冲锋枪、狙击枪或手枪：键鼠在等待复活时按 1–4，活着时按 B 循环切换；触屏在等待复活时点屏幕下方的按钮。每次复活都会补一颗高爆手雷和一颗闪光弹。

## 人物

士兵动作是程序生成的：脚步贴地（两段 IK），按移动方向迈出不同的步子（前跑、后退、侧移交叉步、斜向），慢走和奔跑按速度混合，起步前倾、刹车后仰，原地转身会挪脚，起跳、落地、受击都有动作。阵亡时布娃娃从当时的姿势接过去，冲击力按武器大小（手枪、步枪、狙击枪/霰弹枪、爆炸）加大，爆头时头部后仰更明显。同一阵营的士兵有轻微的颜色差异，并有柔和的轮廓光。

## 地图

烈沙镇是原创的沙漠小镇。中门是只有约 1.8 米宽的单扇石门，半开的木门可以当掩体；中路两侧门面错落，有沙袋、货摊和木箱，中路南端被装卸场隔开，进攻方要从左右两侧绕进中路。B 区北侧的染坊有一扇正对庭院的射击窗。A 区新增 1.2/1.6 米的阶梯露台，以及从巴扎侧面拐进 A 的小巷。光照烘焙已随新布局重新生成。

## 武器与投掷物

M18 可连续射击，K5 适合移动射击，U45 射速较低、单发更重。S8 近距离散射，逐发装填时可开枪打断。FA-2 是双方通用步枪，S40 是轻型双倍率狙击步枪，L60 使用一百发弹箱。

投掷物最多携带四枚，其中闪光弹最多两枚，其余每类一枚。按下左键拉环，按住蓄力（力度从 45% 用约 0.65 秒升到 100%，准星上方有力度弧，地上有轨迹和落点预览），松开投出；右键近抛，两键一起按住后松开任一键可中抛。阵亡者会把主武器（没有就掉手枪）和手里的投掷物抛在地上。高爆手雷造成范围伤害，闪光弹使视野变白，烟雾遮挡视线并扑灭火焰。进攻方购买燃烧瓶，防守方购买燃烧弹。

## 画质

菜单可以选择「自动」「流畅」「均衡」「高」「极致」。自动时：没有使用显卡则选流畅；触屏设备选均衡（显卡名称能认出高端移动 GPU 时选高）；台式机选高（能认出较强独立显卡时选极致）。手动更改画质会重新加载页面。

渲染分辨率默认 100%，也可选 85%、70% 或 50%。动态分辨率默认在手机和软件渲染上打开、在普通台式机上关闭。它最低降到当前所选分辨率的 75%，帧时间回到约 60 帧后再升回去。流畅在软件渲染下按 1 倍像素渲染。均衡及以上开启 MSAA；分辨率低于 100% 时，最终画面会做轻度锐化。各向异性过滤为流畅 4、均衡 8、高和极致 16，并且不会超过显卡上限。

勾选「显示帧率」后，雷达下方显示帧数和帧时间。按 F3 开关详细信息：分辨率、绘制调用、三角形数量和当前预设。计数器避开顶部比分、触屏摇杆、底部武器栏和右侧动作键。若浏览器没有使用显卡，主菜单会提示到系统设置里打开图形加速。

## 项目结构

`index.html` 包含加载器、菜单及 HUD；`touch.css` 提供横屏布局和触屏控件，`ui.css` 提供面板、购买卡片和击杀徽记的样式。脚本按依赖顺序载入，共用 `window.G`。

| 脚本 | 用途 |
| --- | --- |
| `vendor/three.min.js` | 本地 three.js r128 渲染引擎 |
| `js/look.js` | 过滤鼠标移动中的突发跳变 |
| `js/core.js` | 共享状态、数学工具、设置、键鼠输入和鼠标锁定 |
| `js/audio.js` | 用 Web Audio 合成枪声、脚步、环境反馈与空间音效 |
| `js/touch.js` | 操作模式、摇杆、瞄准曲线、自定义键位，调试状态见 `G.Touch` |
| `js/textures.js` | 按画质载入扫描贴图、生成程序贴图并打包世界材质 |
| `js/surfaces-worker.js` | 在后台线程加载、生成并打包世界贴图 |
| `js/map.js` | 烈沙镇布局、碰撞查询、射线检测、导航和雷达底图 |
| `js/mapgeo.js` | 构造用于小镇渲染和光照烘焙的静态几何数据 |
| `js/gfx.js` | 画质预设、着色器、天空、静态与角色阴影、烘焙光照 |
| `js/video.js` | 渲染分辨率、MSAA、辉光、锐化和帧率显示 |
| `video.css` | 画质选项和帧率计数的样式 |
| `ui.css` | 面板、菜单分区、购买卡片和击杀徽记 |
| `js/geom.js` | 角色与武器建模共用的几何工具 |
| `js/gunmodels.js` | 生成各武器的三维模型 |
| `js/mapmesh.js` | 将小镇、道具和贴花组装成可渲染网格 |
| `js/fx.js` | 烟尘、命中和其他战斗特效 |
| `js/weapons.js` | 武器数据、射击、后坐力、换弹和掉落物 |
| `js/viewmodel.js` | 第一人称手臂、武器与动作 |
| `js/player.js` | 移动物理、玩家控制、死亡镜头与观战 |
| `js/ragdoll.js` | 角色倒地时的布娃娃物理 |
| `js/soldier.js` | 第三人称士兵：两阵营外观、骨骼动画、投掷与换弹动作、远近模型 |
| `js/bots.js` | 机器人感知、路线、战术与交战 |
| `js/game.js` | 回合、经济、购买、伤害、胜负与炸弹逻辑 |
| `js/icons.js` | 把武器模型渲成侧视白剪影，供界面引用 |
| `js/hud.js` | 雷达与大地图、准星、状态条、击杀信息、购买卡片、记分板和击杀徽记 |
| `js/main.js` | 启动、渲染循环、动态分辨率、着色器预热、菜单和暂停 |
